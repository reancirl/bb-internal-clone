# Documentation Standards

Always generate artifacts using:

- Clear hierarchical markdown
- No excessive prose
- Structured sections
- Actionable implementation steps
- Technical rationale
- Validation criteria
- Risk analysis
- File impact lists

Preferred artifact types:
- task.md
- implementation_plan.md
- walkthrough.md
- architecture.md

Formatting style:
- concise
- professional
- organized
- engineering-documentation focused
